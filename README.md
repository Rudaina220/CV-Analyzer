# Pour

Upload a résumé and a job description, and Pour tells you how well they match what skills line up, what's missing, and how to close the gap. Runs entirely in your browser using Groq's free API.

## Features

- Upload résumé and job description as PDF, DOCX, or plain text (or just paste the JD)
- AI-powered match score, matched skills, missing skills, and improvement suggestions
- Groq API key is entered once and saved locally in your browser never sent anywhere but Groq

## How to use

1. Open `resume-analyzer.html` in your browser.
2. Click the ⚙ icon and paste in a free Groq API key ([get one here](https://console.groq.com/keys)).
3. Upload your résumé and the job description.
4. Click **Analyze match** and review your results.
